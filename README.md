**Instalacja**

```
git clone https://github.com/Przemek1337/Sudoku-Hacker.git
cd Sudoku-Hacker
```

```
pip install -r requirements.txt
```

**Użycie** 

W folderze ```notebooks``` w evaluate.ipynb mamy możliwość podglądu samej detekcji liczb w gridzie sudoku bez wywoływania i uzupełniania jej
```train.env``` odpowiada za nasz folder treningowy, gdzie możemy trenować modele, zapisywać je oraz plotować ich metryki

**Aplikacja**

Aby uruchomić aplikację należy wpisać w wiersz poleceń:

```python3 /app/main.py```

bądź po prostu uruchomić plik ```main.py``` ręcznie rozwijając folder ```app```
